## Que es
Apuntes de cuando estudie licenciatura en fisica, un repositorio personal para hacer seguimiento y nunca dejar de aprender

## Problemas conocidos
- El repositorio actualmente es solo un contenedor sin inteligencia, se propone utilziar algoritmos de N-gramas y OCR para así convertir apuntes en embeddings inteligentes capaces de ser referenciados por sistemas RAG
- Quiero escanear cuadernos pero aún falta una forma de convertirlos deterministicamente a Markdown de forma costo-eficiente
